# Declaración de Uso de Inteligencia Artificial

**Herramienta utilizada:** Claude (Anthropic).

**Modo de uso:** como asistente técnico de consulta, a lo largo de una conversación interactiva. Cada decisión de arquitectura (stack tecnológico, base de datos, patrón de integración con el core legado, enfoque del incidente simulado) fue evaluada, cuestionada y decidida por mi persona tras discutir alternativas y trade-offs con la herramienta. El código generado fue ejecutado, depurado y validado por mi persona en mi propio entorno de desarrollo.

**Componentes y actividades donde se aplicó:**

- Discusión y justificación de decisiones de arquitectura y stack tecnológico.
- Generación de código base para revisión y ajuste.
- Configuración de infraestructura como código.
